A multi-page, cross-platform utility application built with **.NET MAUI**. This project integrates daily tools into a single application, demonstrating multi-page navigation, user input validation, 
and dynamic UI state management.

## Features
* **Multi-Page Navigation:** Built with a central Home Page providing seamless routing to different utility modules.
* **Loan Calculator (Kredi Hesaplama):** Computes loan installments, interest rates, and total payment amounts based on user-defined parameters.
* **BMI Calculator (Vücut Kitle İndeksi):** Evaluates Body Mass Index using height and weight inputs, providing real-time health categorizations.
* **Dynamic Theme Customization:** Allows users to change the application's background color dynamically, showcasing real-time UI updates and state management.

## Tech Stack
* **Language:** C#
* **Framework:** .NET MAUI
* **UI/Layout:** XAML
* **Architecture:** Event-driven programming with multi-page routing
